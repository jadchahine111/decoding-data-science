# 🐍 Python Essentials — Fast Track Crash Course

> Crash course covering the core building blocks of Python. Notes from the **Decoding Data Science** course.

## 📚 Contents

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 1 | [**Data Types**](./data-types.md) | Variables, naming rules, and the core types: integers, floats, strings, booleans |
| 2 | [**Data Structures**](./data-structures.md) | The 4 essentials: lists, tuples, sets, and dictionaries |
| 3 | [**Control Flow**](./control-flow.md) | Making decisions (`if`/`elif`/`else`) and repeating actions (`while`, `for`) |

## 🎯 What This Course Covers

- **1. Data Types** — How Python stores single values, dynamic typing, math operators, and the truthiness rules for booleans.
- **2. Data Structures** — How to group values together, and when to reach for a list vs. a tuple vs. a set vs. a dictionary.
- **3. Control Flow** — How to make your programs react to conditions and repeat work without copy-pasting.
- **4. Functions** — How to package logic into reusable blocks (*Don't Repeat Yourself*) and understand where variables live.
- **5. File Handling** — How to make data persist by saving it to and loading it from files on disk.
